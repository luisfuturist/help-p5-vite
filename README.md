# help-p5-vite

p5.js creative-coding boilerplate built with Vite and TypeScript.

## Features

- Vite dev server with fast HMR
- ESM modules and strict TypeScript
- p5.js sketch entry point

## Setup

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # production build
```

The sketch lives in `src/sketch.ts`.
